# News-Article Assignment

## Tech Stack
- React + TypeScript
- Axios
- Supabase (PostgreSQL)
- React Router
- Vite

## Requirements
- Node.js
- npm

## How to run
1. Clone the repository
- git clone https://github.com/ameliayay/news-article-assignment.git

2. Navigate into the project folder
- cd news-article-assignment

3. Install dependencies
- npm install

4. Start development server
- npm run dev

5. Open in browser
- http://localhost:5173

## Features
- Create new articles
- Edit existing articles
- Delete articles
- Search articles
- Pagination
- Refresh button
- Form validation
- Data persistence with Supabase
