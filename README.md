# News-Article Assignment

## Requirements
- Node.js
- npm

## How to run
1. Clone the repository
- git clone https://github.com/ameliayay/news-article-assignment.git

2. Navigate into the project folder
- cd news-article-assignment

3. Install dependencies
- npm install

4. Start development server
- npm run dev

5. Open in browser
- http://localhost:5173

## Notes
- This project uses LocalStorage for data persistence.
- Axios is used to simulate a mock API structure.
- No backend is required.
